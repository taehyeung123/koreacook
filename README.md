## ✅ 사장님이 직접 해야 할 일 (중요도 순)

### 1. 폼 백엔드 연동 (구글시트 + 이메일 알림) — 복사·붙여넣기 3분
현재 폼은 백엔드 미연동 상태라 제출 시 "전화/카카오톡 안내" 메시지가 나옵니다.
연동하면 **제출 즉시 구글시트에 쌓이고 rnjsxogud2165@gmail.com 으로 알림 메일**이 갑니다.

1. https://sheets.new 접속 → 시트 이름을 `코요아 대전점 상담DB`로 변경
2. 메뉴 **[확장 프로그램] → [Apps Script]**
3. 기본 코드를 지우고, 이 저장소 **`apps-script/Code.gs` 내용 전체**를 붙여넣기 → 💾 저장
4. 우측 상단 **[배포] → [새 배포]** → ⚙️ 유형 **웹 앱** 선택
   - 실행 계정: **나** / 액세스 권한: **모든 사용자** → [배포]
5. 권한 승인 팝업: 계정 선택 → "확인되지 않은 앱" 경고가 나오면 **[고급] → [프로젝트로 이동(안전하지 않음)] → [허용]**
   (내 계정에서 내가 만든 스크립트라 안전합니다)
6. 발급된 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사
7. 마무리 두 가지 방법 중 택 1:
   - **URL을 Claude 채팅에 붙여넣기** → 연결·테스트·배포까지 자동으로 마무리됩니다 (권장)
   - 직접: `js/main.js` 맨 위 `CONFIG.FORM_ENDPOINT: ''`에 붙여넣고 커밋·푸시

> 알림 받을 이메일을 바꾸려면 `Code.gs` 상단 `NOTIFY_EMAIL` 값을 수정하세요.
> 참고: Formspree URL을 넣어도 동작하도록 폼 코드가 양쪽을 지원합니다.
